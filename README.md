# 🌱 AgriShield AI - Smart Farming Doctor

AgriShield AI is a simple app that acts like a doctor for plants. Built with Python and Streamlit, it helps farmers quickly fix plant diseases. You just upload a photo of a sick leaf. The AI then tells you the crop name, the disease it has, and how to cure it. This helps farmers save their crops and grow more food.

---

## 🚀 Project Roadmap

Here is the future plan for developing AgriShield AI:

### 📍 Phase 1: Core Features (Current)
* [x] Simple web interface using Streamlit
* [x] Leaf image upload and AI disease diagnosis
* [x] Basic treatment advice (Chemical and Cultural)
* [x] Multilingual support (English & Kannada)

### ⚡ Phase 2: Enhancements (Next Steps)
* [ ] **Offline Mode:** Allow farmers to use the app without an internet connection.
* [ ] **More Languages:** Add support for other regional Indian languages (Hindi, Telugu, Tamil, etc.).
* [ ] **E-Marketplace Integration:** Connect farmers directly with local shops to buy recommended fertilizers or tools.

### 🌐 Phase 3: Advanced AI & Community
* [ ] **Weather-Based Alerts:** Give advice based on local weather conditions.
* [ ] **Community Forum:** A space for farmers to chat with agriculture experts.
* [ ] **Voice Support:** Allow users to listen to the advice instead of reading it.
